1. Install and first open

  1. Open the DMG and drag Automatic Photo Importer onto Applications.
  2. Open it from Applications. Works on Macs with Apple silicon (M1 or later) and macOS 14 Sonoma or later.
“Apple could not verify…” on first open? This build is not notarized by Apple. Do this once:
  1. Try to open the app, then click Done (or OK).
  2. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to Automatic Photo Importer, then confirm with your password.
If macOS says the app “is damaged”, run this in Terminal, then open it again:
xattr -dr com.apple.quarantine "/Applications/Automatic Photo Importer.app"

When macOS asks for access to removable volumes or the camera, click Allow: the app needs it to read cards and write to backup drives.

2. First setup: where backups go

Go to Settings → Storage & folders.

  • Choose location…: pick the photo backup folder. It can be on your Mac or on an external HDD/SSD (not a camera card or USB stick). A missing folder is created on the first import.
  • Use a separate video folder: keep videos in their own folder, on the same drive, another drive, or any folder depth (for example photos on Drive1/photobackup, videos on Drive2/folder1/folder2).
  • Copy policy: One destination, Copy to both destinations (a verified copy on two disks) or Fill first, then second.
  • Folder structure: choose Date, then camera or Camera, then date, turn date levels on or off, and choose how photos and videos are split by format. The previews show exactly where the next photo, video, JPEG and voice memo will land.
  • Edited exports folder: the folder name used for edited exports inside each month.

3. Import page

Media tab (cards and cameras)

  • Insert a memory card or connect a camera by USB: it appears under Sources & queue.
  • Choose media folders…: add a folder that already holds photos as a source.
  • Scan / Scan all: read a source without copying; shows file counts, formats and cameras.
  • Start (or Start all selected in the title bar): plan the import, review it, then copy. Each copy is checked with SHA-256.
  • Stop (or Stop imports): cancels running work. Finished files stay; importing again resumes.
  • List view / Grid view: change how sources are shown. Click a file to see its preview and EXIF.
  • With Automatic import on (Settings → Importing), imports start as soon as a chosen card connects.

Files & folders tab (every file of a drive or folder)

  • Back up drives or folders…: copy every file into the library, not only photos and videos. Photos and videos are filed by your date and camera rules like any import; every other file (documents, archives, camera index files, Finder aliases) goes to Unknown files in the folder of its date, for example 2026/202610/Unknown files/. macOS ._ files and .DS_Store are not copied.
  • There is no Additive or Mirror mode. A file you later delete from the drive stays in the library; nothing is ever removed or moved aside because it left the drive. Files already in the library are recognized by their contents and not copied twice.
  • Every name the app writes is valid on macOS, Windows and Linux (characters Windows refuses, trailing dots or spaces and names such as CON are adjusted, and two names differing only by case never share a folder), so a library drive can move between computers.

Import overview and Destinations

  • The overview shows sources, active jobs, speed, files done and destination space. Hide the import overview collapses it.
  • Destinations lists each backup folder with its drive (“A006 › photobackup”), its video folder, a storage bar and drive activity. Change opens the copy policy; Check folder layout checks whether existing files match your folder rules.

4. Library browser

Browse everything you have imported, read-only. Nothing is moved or renamed here.

  • Library menu: pick a destination library. Browse a folder… (folder icon) adds any other folder to browse; × removes it from the list.
  • Categories: virtual columns such as Date › Camera › Format › Files. Real folders: the actual folders on disk.
  • Click a row to narrow the next columns. Command-click adds more choices in the same column. Every column only shows what matches the columns before it.
  • Back / Forward: step through your selections. Clear all resets them.
  • Search names and Sort filter and order the Files column.
  • RAW + JPEG (on by default): a RAW and the JPEG/HEIF taken with it (same name, same EXIF time and camera) show as one photo marked “+ NEF”.
  • Click a file to preview it with camera, lens, date and exposure. Full EXIF shows every tag; Show in file manager reveals it in Finder.
  • The status line shows indexing progress with Refresh index / Stop indexing and a Placement filter (for example “Needs organization”).
  • Drag a column edge to change its width; drag the handle under the columns to change their height (double-click it to fill the window).
  • Keyboard: arrow keys move, Space selects, Esc clears or closes the preview.

Building a view (Virtual hierarchy panel)

  • Fields: click a field (Date, Camera, Lens, ISO…) to add it as the last column, or drag it to the exact place in Levels.
  • Presets: click one to use it, or drag it into Levels to insert all its columns.
  • Click a level to set its options (date granularity, aperture/ISO/shutter ranges, name or format grouping). Drag levels to reorder; Clear removes them all.
  • Type a name and click Save current view to keep it as your own preset (rename ✎ or delete ×). Restore default view goes back to Date › Camera › Format.

5. Library tools

Organize

  • Check folder layout: find files that are not where your folder rules put them.
  • Review changes…: preview the new structure; Organize now applies it. Originals wait in a recovery area until you release them, so you can undo.
  • Organize a folder → Choose folder…: organize another folder in place.
  • Edit folder rules: opens Settings → Storage & folders.
  • A Drive backups folder made by an earlier version is organized into the library too: Check folder layout lists its files as misplaced, and Review changes… → Organize now files its photos and videos by date and camera and everything else (Finder aliases included) in Unknown files. A file the library already has is kept in the recovery area as a duplicate, not deleted. Removable ._ files follow Remove macOS ._ files; the drive marker and .DS_Store go with the emptied folder, and the Drive backups folder is removed once empty. The whole move is listed under Organization recovery and can be undone.

Duplicates

  • Where to look → Choose folder…, then Scan for duplicates.
  • Choose Choose every keeper (you decide each group) or Suggest keepers for identical files. Removed copies go to the recovery area and can be undone.

Recovery & cleanup

  • Organization recovery lists past organizations you can undo; Refresh list rereads it. Maintenance → Clean up releases recovery data you no longer need, after showing what will happen.

6. Activity

  • Queue: running and waiting jobs. Stop all cancels them.
  • Same name, same contents: when a file of an import is already in the library under its name, the app compares them: the size first, then the first 64 KB (where a photo keeps its date, camera and dimensions), and only if those agree, the SHA-256 of that one pair. A different file is copied under a new name (Conflicts folder or a number), without asking. The same file is not copied and is listed on the import's card and in Activity while the import goes on; nothing waits for you. Expand a row to see both files, then choose Skip (the default), Overwrite or Keep both, or use Skip all, Overwrite all, Keep both for all. Choices made during the import are applied when it ends; later choices are applied at once. Stop all skips every conflict not applied yet and stops the import. Overwrite never deletes the library file: it goes to recovery storage, a verified copy takes its name, and Undo overwrite puts it back. On every system a name that differs only in upper and lower case counts as the same name.
  • History: finished imports and what they did.
  • Issues: errors and warnings grouped by cause. Copy all details for support; Clear all errors when done.

7. Settings

  • General: app language (English, 简体中文, 繁體中文, 日本語), text size, appearance (System / Light / Dark) and accent colour.
  • Storage & folders: backup folders, copy policy, folder structure and edited exports folder (see section 2).
  • Importing: Automatic import; Verify each copy after copying (reads each copy back; off is faster); Files & folders: shows where files other than photos and videos go (no mode to choose: files deleted from the drive stay in the library); After an import: offer to delete originals that are verified in the backup (two-step confirmation, off by default), and eject drives automatically after a clean import.
  • Remove confirmed duplicates, one switch per kind of run. Library organization (on): after organizing finishes without errors, originals already at their destination are checked again and deleted instead of kept for undo (the Organize page can change it for one run). Drive transfers (on): after an import from a drive or folder finishes without errors and is not stopped, its files that were already in the library are read again on both sides and deleted from the source; the review says how many before you start. Camera imports (off): nothing on a USB camera or a camera card (a card in a reader, or removable flash) is ever deleted, whatever this switch or any other says. Updating to this version sets these defaults once for everyone, including anyone who had turned the old switch off; a choice made afterwards is kept.
  • File handling: what to do with files without date or camera (Move to a folder, Leave where they are, Use file date); unrecognized file types (Skip automatically, Copy to Other files folder, Ask me, or a saved rule per extension); same name but different content (Conflicts folder or Add a number); collect 0-byte problem files; Clean up Mac system files (on by default, on every computer): imports skip Finder's .DS_Store and ._ files on the card, and imports and organizations remove them from the folders they write to. ._ files that hold tags or other data are kept, and the card is never changed. Turn it off to have a Files & folders import take them.
  • Devices: remembered drives (with the cameras found on them) and ignored drives.
  • Performance: drives imported at once, CPU threads and memory limit; Reset to defaults.
  • Diagnostics: log detail, Open log folder, Export logs… to share with support.

8. Sidebar

  • Sources: connected cards, cameras and folders; the refresh button rescans; the eject button safely ejects a card.
  • Destinations: each backup folder with free space and its current activity.

9. Safety rules

  • Nothing on a card or source is moved, changed or deleted (unless you confirm deleting verified originals).
  • Identical files are skipped and listed so you can choose. A different file with the same name never overwrites: it goes to a Conflicts folder or gets a number. Overwrite, when you choose it, keeps the replaced file in recovery storage until you undo or release it.
  • Stop or unplug at any time; import again and the app checks what was written and continues.

1. 安装与首次打开

  1. 打开 DMG，把 Automatic Photo Importer 拖到 Applications（应用程序）。
  2. 从“应用程序”打开。支持 Apple 芯片（M1 或更新）的 Mac，需要 macOS 14 Sonoma 或更高版本。
首次打开提示“无法验证开发者”？此版本未经 Apple 公证，只需操作一次：
  1. 先尝试打开应用，然后点「完成」或「好」。
  2. 打开「系统设置 → 隐私与安全性」，向下滚动，点 Automatic Photo Importer 旁的「仍要打开」，输入密码确认。
如果提示应用“已损坏”，在“终端”中运行下面的命令后再打开：
xattr -dr com.apple.quarantine "/Applications/Automatic Photo Importer.app"

macOS 询问是否允许访问可移除宗卷或相机时，请点「允许」：应用需要它来读取存储卡并写入备份硬盘。

2. 首次设置：备份位置

打开「设置 → 存储与文件夹」。

  • 「选择位置…」：选择照片备份文件夹，可以在 Mac 上或外置硬盘/SSD 上（不能是相机存储卡或 U 盘）。不存在的文件夹会在首次导入时创建。
  • 「为视频使用单独的文件夹」：视频单独存放，可在同一硬盘、另一块硬盘或任意多层文件夹中（例如照片放在 Drive1/photobackup，视频放在 Drive2/folder1/folder2）。
  • 「复制策略」：一个目标、复制到两个目标（两块磁盘各一份校验过的副本），或先存满第一块再用第二块。
  • 「文件夹结构」：选择先按日期或先按相机，开关各级日期文件夹，并选择照片和视频如何按格式分开。预览会显示下一张照片、视频、JPEG 和语音备忘录的确切位置。
  • 「编辑导出文件夹」：每个月份文件夹内存放编辑后导出文件的文件夹名称。

3. 导入页面

  • 媒体：插入存储卡或用 USB 连接相机，它会出现在「来源与队列」中。「选择媒体文件夹…」可把已有照片的文件夹加为来源。
  • 「扫描」/「扫描全部」：只读取不复制，显示数量、格式和相机。
  • 「开始」：规划、审核后复制，每份副本都用 SHA-256 校验。「停止」：取消进行中的任务，已完成的文件保留，再次导入会继续。
  • 列表/网格视图切换；点击文件查看预览和 EXIF。在「设置 → 导入」中开启「自动导入」后，插卡即开始导入。
  • 文件和文件夹：「备份磁盘或文件夹…」把每个文件都复制到媒体库，不只是照片和视频。照片和视频与普通导入一样按日期和相机规则归档；其他文件（文档、压缩包、相机索引文件、Finder 替身）放入对应日期文件夹中的 Unknown files，例如 2026/202610/Unknown files/。macOS 的 ._ 文件和 .DS_Store 不会复制。不再有「累加」或「镜像」模式：之后从磁盘删除的文件仍保留在媒体库中，任何文件都不会因为离开磁盘而被删除或移走；媒体库中已有的文件按内容识别，不会重复复制。应用写入的每个名称在 macOS、Windows 和 Linux 上都有效（Windows 不允许的字符、结尾的点或空格以及 CON 等名称会被调整，只有大小写不同的两个名称不会放在同一文件夹），媒体库磁盘可以在不同电脑之间使用。
  • 「目标」显示每个备份文件夹所在硬盘（如“A006 › photobackup”）、视频文件夹、存储条和硬盘活动；「检查文件夹结构」检查现有文件是否符合文件夹规则。

4. 分类预览

  • 只读浏览已导入的内容，这里不会移动或重命名任何文件。
  • 「资料库」菜单选择目标资料库；文件夹图标「浏览文件夹…」可加入任意其他文件夹，× 可移除。
  • 「分类浏览」：日期 › 相机 › 格式 › 文件等虚拟栏位；「实际文件夹」：磁盘上的实际文件夹。
  • 点击一行会筛选后面的栏位；按住 Command 点击可在同一栏多选。每一栏只显示符合前面栏位选择的内容。「后退」/「前进」切换选择历史，「全部清除」重置。
  • 「搜索名称」和「排序」作用于文件栏。「RAW + JPEG」（默认开启）：同名、EXIF 时间和相机相同的 RAW 与 JPEG/HEIF 合并显示为一张，并标注“+ NEF”。
  • 点击文件可预览并查看相机、镜头、日期和曝光；「完整 EXIF」显示全部标签；「在文件管理器中显示」在访达中显示。
  • 拖动栏位边缘调整宽度；拖动栏位下方的手柄调整高度（双击恢复填满窗口）。键盘：方向键移动，空格选择，Esc 清除或关闭预览。
  • 虚拟层级面板：点击「字段」把它加到最后一层，或拖到「层级」中的指定位置；点击「预设」直接使用，或拖入层级插入其全部栏位；点击某一层设置选项，拖动可调整顺序，「清除」移除全部层级；输入名称后点「保存当前视图」保存为自己的预设（✎ 重命名、× 删除），「恢复默认视图」回到 日期 › 相机 › 格式。

5. 资料库工具

  • 整理：「检查文件夹结构」找出位置不符合规则的文件；「预览更改…」预览新结构，「立即整理」执行。原文件会保留在恢复区直到你释放，可以撤销。「整理文件夹 → 选择文件夹…」原地整理其他文件夹；「编辑文件夹规则」打开设置。旧版本建立的 Drive backups 文件夹也会整理进媒体库：「检查文件夹结构」会把其中的文件列为位置不符，「预览更改…」→「立即整理」把照片和视频按日期和相机归档，其他文件（包括 Finder 替身）放入 Unknown files。媒体库中已有的文件作为重复项保留在恢复区，不会删除。可移除的 ._ 文件按「移除 macOS ._ 文件」设置处理；磁盘标记和 .DS_Store 随清空的文件夹一起移除，Drive backups 清空后也会被移除。整个过程列在「整理恢复」中，可以撤销。
  • 重复文件：在「查找位置」中「选择文件夹…」，然后「扫描重复文件」；可以逐组自行选择保留的文件，或让应用为完全相同的文件建议保留项。移除的副本进入恢复区，可以撤销。
  • 恢复与清理：「整理恢复」列出可撤销的整理；「刷新列表」重新读取；「维护 → 清理」在说明后果后释放不再需要的恢复数据。

6. 活动

  • 「队列」：进行中和等待中的任务，「全部停止」可取消。「历史记录」：已完成的导入。「问题」：按原因分组的错误和警告，可「复制全部详情」或「清除所有错误」。
  • 「同名且内容相同」：导入的文件在图库中已有同名文件时，应用会依次比较：先比大小，再比前 64 KB（照片的日期、相机和尺寸都在这里），两者都一致时才计算这一对文件的 SHA-256。内容不同的文件会直接以新名称复制（冲突文件夹或编号），不会询问。内容相同的文件不会复制，而是在导入继续进行的同时列在该导入的卡片和「活动」中，不会让导入等待你。展开一行可查看两个文件，然后选择「跳过」（默认）、「覆盖」或「保留两者」，也可以使用「全部跳过」「全部覆盖」「全部保留两者」。导入过程中做出的选择会在导入结束时执行，之后的选择会立即执行。「全部停止」会跳过所有尚未执行的冲突并停止导入。「覆盖」绝不会删除图库中的文件：它会移入恢复存储，由一份已校验的副本取代其名称，「撤销覆盖」可将其放回。在所有系统上，仅大小写不同的名称都视为同一名称。

7. 设置

  • 通用：界面语言、文字大小、外观（跟随系统/浅色/深色）和强调色。
  • 存储与文件夹：备份文件夹、复制策略、文件夹结构、编辑导出文件夹（见第 2 节）。
  • 导入：自动导入；复制后逐一校验（关闭更快）；「文件和文件夹」显示照片和视频以外的文件存放位置（无需选择模式：从磁盘删除的文件仍保留在媒体库中）；导入完成后：提供删除已在备份中校验过的原文件（两步确认，默认关闭）、导入无误后自动推出驱动器。
  • 删除已确认的重复文件，按运行类型各一个开关。资料库整理（开）：整理无错误完成后，再次校验已在目标位置的原文件并将其删除，而不是保留以供撤销（可在“整理”页面为单次运行更改）。驱动器传输（开）：从驱动器或文件夹导入无错误完成且未停止后，对已在资料库中的文件在两侧再次读取校验，然后从来源删除；开始前的预览会显示数量。相机导入（关）：USB 相机或相机卡（读卡器中的卡或可移动闪存）上的任何内容都不会被删除，无论此开关或其他设置如何。更新到此版本时会为所有人设置一次这些默认值（包括曾关闭旧开关的用户）；之后所做的选择会被保留。
  • 文件处理：没有日期或相机的文件（移到文件夹 / 保持原位 / 使用文件日期）；无法识别的文件类型（自动跳过 / 复制到“其他文件”文件夹 / 询问我，或按扩展名保存规则）；同名但内容不同（冲突文件夹 / 添加编号）；收集 0 字节问题文件；清理 Mac 系统文件（默认开启，所有电脑上都是）：导入时跳过存储卡上 Finder 的 .DS_Store 和 ._ 文件，导入和整理时从写入的文件夹中删除它们。含有标签或其他数据的 ._ 文件会保留，存储卡不会被改动。关闭后，“文件和文件夹”导入会包含它们。
  • 设备：记住的驱动器（含其中发现的相机）和已忽略的驱动器。
  • 性能：同时导入的驱动器数、CPU 线程、内存上限，「恢复默认」。
  • 诊断：日志详细程度、「打开日志文件夹」、「导出日志…」。

8. 侧栏

  • 「来源」：已连接的存储卡、相机和文件夹；刷新按钮重新扫描，推出按钮安全推出存储卡。「目标」：各备份文件夹的可用空间和当前活动。

9. 安全规则

  • 存储卡或来源上的任何内容都不会被移动、修改或删除（除非你确认删除已校验的原文件）。
  • 相同的文件会被跳过并列出供你选择；同名但内容不同的文件绝不会覆盖，而是放进冲突文件夹或添加编号。你选择「覆盖」时，被替换的文件会保存在恢复存储中，直到你撤销或释放它。
  • 随时可以停止或拔出；再次导入时应用会检查已写入的内容并继续。
